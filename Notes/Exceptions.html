What Exceptions Are

An exception is an error that happens while a program is running. When Python hits a problem it cannot continue past, it raises an exception. If you do not handle it, the program stops and prints a traceback (error message).

Examples of things that raise exceptions:

  • Dividing by zero
  • Using a variable that does not exist
  • Accessing a list index that is out of range
  • Passing the wrong type to an operation
Exception vs syntax error A syntax error means the code is written incorrectly and Python refuses to run it at all. An exception happens during execution when something goes wrong at runtime.

Basic flow:

  1. Python runs code in the try block
  2. If an exception occurs, Python jumps to the matching except block
  3. If no exception occurs, the except block is skipped

Handling with try/except

Use try/except to catch an exception and respond gracefully instead of crashing.

Code

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")

Output

Cannot divide by zero

Catching the Exception Object

You can capture the exception in a variable with as to read the error message.

Code

try:
    value = int("abc")
except ValueError as error:
    print("Conversion failed:", error)

Output

Conversion failed: invalid literal for int() with base 10: 'abc'

Multiple except Blocks

Handle different exception types with separate blocks:

Code

def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("Error: division by zero")
    except TypeError:
        print("Error: numbers required")

print(safe_divide(10, 0))
print(safe_divide(10, "2"))

Output

Error: division by zero
None
Error: numbers required
None
Only catch exceptions you can handle Do not use a bare except: to silence every error. Catch specific types so real bugs are not hidden.

else and finally

A full exception block can have up to four parts: try, except, else, and finally.

Block Runs when
try Always first — code that might fail
except An exception was raised in try
else No exception was raised in try
finally Always — whether or not an exception occurred

Code

def divide(a, b):
    return a / b

try:
    result = divide(10, 2)
except ZeroDivisionError:
    print("Cannot divide by zero")
else:
    print("Result:", result)
finally:
    print("Done")

Output

Result: 5.0
Done

Use finally for cleanup that must run no matter what, such as closing a file or releasing a resource.

Raising Exceptions

You can create your own exception with the raise keyword. This is useful when input is invalid or a rule is broken.

Code

def set_age(age):
    if age < 0:
        raise ValueError("Age must be positive")
    print("Age set to", age)

try:
    set_age(-1)
except ValueError as error:
    print("Caught:", error)

Output

Caught: Age must be positive
Raise what fits Pick an exception type that matches the problem. Use ValueError for bad values, TypeError for wrong types, and so on.

Common Exception Types

Python has many built-in exception types. These are the ones beginners encounter most often:

Exception Typical cause
ZeroDivisionError Dividing by zero
ValueError Right type, but invalid value (e.g. int("abc"))
TypeError Operation on the wrong type (e.g. "a" + 1)
IndexError List/tuple index out of range
KeyError Dictionary key does not exist
NameError Variable or name is not defined
AttributeError Object has no such attribute or method

ZeroDivisionError

Code

try:
    print(10 / 0)
except ZeroDivisionError as error:
    print(error)

Output

division by zero

ValueError

Code

try:
    number = int("abc")
except ValueError as error:
    print(error)

Output

invalid literal for int() with base 10: 'abc'

TypeError

Code

try:
    message = "hello" + 5
except TypeError as error:
    print(error)

Output

can only concatenate str (not "int") to str

IndexError

Code

try:
    nums = [1, 2, 3]
    print(nums[10])
except IndexError as error:
    print(error)

Output

list index out of range

KeyError

Code

try:
    user = {"name": "Ada"}
    print(user["email"])
except KeyError as error:
    print(error)

Output

'email'

NameError

Code

try:
    print(undefined_var)
except NameError as error:
    print(error)

Output

name 'undefined_var' is not defined

AttributeError

Code

try:
    count = 5
    count.append(1)
except AttributeError as error:
    print(error)

Output

'int' object has no attribute 'append'
Tip: avoid some errors before they happen Use dict.get("key") instead of dict["key"] when a missing key is normal. Check len(items) before indexing when possible.

Summary

Exceptions report runtime problems. Use try/except to handle them, raise to signal errors yourself, and learn common types so error messages make sense.

Concept One-line meaning
Exception Runtime error that stops normal flow unless handled
try Run code that might fail
except Handle a specific exception type
else Runs if try succeeded with no exception
finally Always runs (cleanup)
raise Trigger an exception on purpose

Notable Observations

  • Unhandled exceptions crash the program. Wrap risky code in try/except when you know how to recover or show a helpful message.
  • Exception names usually end in Error. The name tells you what went wrong: ZeroDivisionError, ValueError, TypeError, and so on.
  • as error gives you the message. Printing the caught exception object shows why Python raised it.
  • Read the error message. Python’s traceback tells you the exception type, the message, and which line caused the problem — that is often the fastest way to debug.
