What Generators Are

A generator is a special kind of iterator that produces values one at a time instead of building a full list in memory. Generators are created by functions that use the yield keyword.

Think of the difference this way:

  • A normal function with return finishes and gives back one result (often a list)
  • A generator with yield can produce many results over time, pausing between each one
Generator = function + yield Any function that contains yield becomes a generator function. Calling it does not run the body immediately — it returns a generator object.

Creating a Generator with yield

Use yield inside a function to send out a value and pause. The function remembers where it stopped and can continue later.

Code

def count_up_to(n):
    current = 1
    while current <= n:
        yield current
        current += 1

gen = count_up_to(3)
print(type(gen))
print(next(gen))
print(next(gen))
print(next(gen))

Output

<class 'generator'>
1
2
3

count_up_to(3) does not return [1, 2, 3]. It returns a generator object. Each call to next() runs the function until the next yield, then pauses.

yield vs return

Both keywords send a value out of a function, but they behave very differently.

return yield
Ends the function? YES — immediately NO — pauses and can resume
How many values? One return value per call Many values, one per yield
What calling returns The returned value (e.g. a list) A generator object
State preserved? NO YES — local variables kept between yields
Memory Often builds everything at once Produces values lazily, one at a time

Same Idea, Two Approaches

With return (builds a list)

def return_numbers(n):
    result = []
    for i in range(1, n + 1):
        result.append(i)
    return result

print(return_numbers(3))
print(type(return_numbers(3)))

Output

[1, 2, 3]
<class 'list'>

With yield (yields one at a time)

def yield_numbers(n):
    for i in range(1, n + 1):
        yield i

print(list(yield_numbers(3)))
print(type(yield_numbers(3)))

Output

[1, 2, 3]
<class 'generator'>
Same final values, different process list(yield_numbers(3)) collects all yielded values into a list. Without list(), the generator produces values on demand, one at a time.

How yield Pauses

When Python hits yield, it sends out a value and freezes the function in place. The next time you ask for a value, execution resumes right after that yield line.

Code

def demo():
    print("start")
    yield 1
    print("middle")
    yield 2
    print("end")

g = demo()
print("created")
print(next(g))
print(next(g))

Output

created
start
1
middle
2

Notice that "end" never prints. The function paused after the second yield and has not finished yet. If you called next(g) again, it would print end and then raise StopIteration.

return inside a generator ends it If a generator function hits a plain return (with or without a value), the generator stops. No more values are produced.

Using a Generator

With a for Loop

The most common way to consume a generator is a for loop. Python calls next() for you until the generator is exhausted.

Code

def count_up_to(n):
    current = 1
    while current <= n:
        yield current
        current += 1

for num in count_up_to(3):
    print(num)

Output

1
2
3

With next()

You can pull values manually. When there are no more values, Python raises StopIteration.

Code

gen = count_up_to(2)
print(next(gen))
print(next(gen))
print(next(gen))   # StopIteration

The third next() raises StopIteration because the generator has no more values to give.

Squares Example

Code

def squares(limit):
    for i in range(1, limit + 1):
        yield i * i

for value in squares(4):
    print(value)

Output

1
4
9
16

Lazy vs All-at-Once

A generator is lazy: it computes the next value only when you ask for it. A function that returns a list builds the entire result in memory first.

Why that matters:

  • Generators use less memory for large sequences
  • You can start processing the first value before all values are ready
  • You can represent infinite or very long sequences (e.g. counting forever)
When to reach for a generator Use one when you need to loop over many values and do not need the full collection in memory at the same time.

Generator Expressions

A generator expression is a compact way to create a generator, similar to a list comprehension but with parentheses instead of square brackets.

Code

squares = (x * x for x in range(1, 5))
print(type(squares))
print(list(squares))

Output

<class 'generator'>
[1, 4, 9, 16]
Syntax Creates
[x * x for x in range(5)] List (all values at once)
(x * x for x in range(5)) Generator (lazy, one at a time)

Summary

Generators produce a stream of values using yield. They pause between values, remember their state, and work well with for loops and next().

Concept One-line meaning
Generator Iterator that yields values one at a time
yield Produces a value and pauses the function
return Ends the function and sends back one final value
Generator function Any function containing yield
next() Gets the next value from a generator
StopIteration Raised when a generator has no more values
Lazy Values are produced on demand, not all upfront

Notable Observations

  • Calling a generator function returns a generator object. The function body does not run until you iterate or call next().
  • yield pauses; return exits. A function can yield many times. return ends the function on the spot.
  • A for loop handles StopIteration for you. That is why for num in count_up_to(3) stops cleanly after the last value.
  • Parentheses create a generator expression; brackets create a list. (x for x in range(5)) is lazy. [x for x in range(5)] is not.
