What Functions Are

A function is a named block of code that performs a specific task. Instead of writing the same logic over and over, you define it once and run it whenever you need it.

Functions help you:

  • Reuse code — write once, use many times
  • Organize code — break a big program into smaller pieces
  • Make code easier to read — a good name explains what the code does

Python already includes many built-in functions, such as print(), len(), and input(). You can also create your own with the def keyword.

Think of a function like a recipe The recipe (definition) says what steps to follow. Each time you cook (call the function), you run those steps again.

Creating a Function

Use def to define a function, then give it a name and a block of indented code. The parentheses after the name are required, even when the function takes no input.

Code

def greet():
    print("Hello!")

greet()

Output

Hello!

Parts of a function definition:

Part Example Meaning
Keyword def Starts the function definition
Name greet What you call later
Parentheses () Hold parameters (can be empty)
Colon : Starts the function body
Body indented lines Code that runs when called
Defining is not the same as running When Python reads def greet():, it stores the function. Nothing prints until you actually call it: greet().

Calling a Function

To call (or invoke) a function, write its name followed by parentheses. Python jumps to the function body, runs it, then comes back.

Code

def show_message():
    print("Function running")

show_message()
show_message()   # can call it again

Output

Function running
Function running

Return Values

Use return to send a value back to the caller. Without return, a function finishes with None.

Code

def add(a, b):
    return a + b

result = add(3, 5)
print(result)
print(add(10, 2))

def no_return():
    print("running")

value = no_return()
print("value:", value)

Output

8
12
running
value: None
print vs return print() shows output on the screen. return gives a value back so you can store it or use it later.

Parameters

A parameter is the variable name listed in the function definition. It is a placeholder that receives data when the function runs.

Code

def greet_name(name):
    print("Hello,", name)

greet_name("Ada")
greet_name("Alan")

Output

Hello, Ada
Hello, Alan

In def greet_name(name):, name is the parameter.

Multiple Parameters

Functions can take more than one parameter, separated by commas.

Code

def describe_pet(animal_type, pet_name):
    print(animal_type, ":", pet_name)

describe_pet("dog", "Rex")

Output

dog : Rex

Default Parameter Values

A parameter can have a default value. You assign it in the function definition with =. If the caller skips that argument, Python uses the default instead.

Parameters with defaults are optional. Parameters without defaults are required — the caller must provide them.

Basic example

def greet_name(name="Guest"):
    print("Hello,", name)

greet_name()        # uses default "Guest"
greet_name("Ada")   # overrides default

Output

Hello, Guest
Hello, Ada

In def greet_name(name="Guest"):, "Guest" is the default value for the name parameter.

Multiple Parameters with Defaults

A function can mix required and optional parameters. Put required parameters first, then optional ones with defaults.

Code

def order_pizza(size, topping="cheese", crust="thin"):
    print(size, topping, "on", crust, "crust")

order_pizza("large")
order_pizza("medium", "pepperoni")
order_pizza("small", crust="thick")
order_pizza("large", topping="veggie", crust="stuffed")

Output

large cheese on thin crust
medium pepperoni on thin crust
small cheese on thick crust
large veggie on stuffed crust
Call size topping crust
order_pizza("large") "large" "cheese" default "thin" default
order_pizza("medium", "pepperoni") "medium" "pepperoni" "thin" default
order_pizza("small", crust="thick") "small" "cheese" default "thick"

Overriding a Default

You can replace a default in two ways:

  • Positional — pass the value in the matching position
  • Keyword — pass name=value to target a specific parameter

Code

def power(base, exponent=2):
    return base ** exponent

print(power(3))                    # 3 squared
print(power(3, 4))                 # override with positional arg
print(power(base=5, exponent=3))   # override with keyword args

Output

9
81
125
Required parameters must come before optional ones This is invalid: def bad(topping="cheese", size):
Python expects: def good(size, topping="cheese"):
Defaults make functions flexible Common settings can live in the definition so simple calls stay short, while callers can still customize behavior when needed.

Arguments

An argument is the actual value you pass when you call a function. Parameters are in the definition; arguments are in the call.

Term Where it appears Example
Parameter Function definition def add(a, b):
Argument Function call add(3, 5)
Easy way to remember Parameters are the empty slots in the recipe. Arguments are the actual ingredients you put in when you cook.

Positional Arguments

By default, arguments are matched to parameters by position (left to right).

Code

def describe_pet(animal_type, pet_name):
    print(animal_type, ":", pet_name)

describe_pet("dog", "Rex")

Output

dog : Rex

"dog" goes to animal_type and "Rex" goes to pet_name because that is the order they appear.

Keyword Arguments

You can pass arguments by name using name=value. Order no longer matters when all arguments are passed by keyword.

Code

def describe_pet(animal_type, pet_name):
    print(animal_type, ":", pet_name)

describe_pet(pet_name="Luna", animal_type="cat")

Output

cat : Luna
Wrong order with positional args causes bugs describe_pet("Rex", "dog") would print Rex : dog. Use keyword arguments when names make the call clearer.

The ** Parameter (Keyword Dict)

A parameter written with two asterisks (**) collects any extra keyword arguments into a dictionary. The keys are the argument names; the values are the argument values.

By convention this parameter is often named kwargs (short for “keyword arguments”), but you can use any valid name: **info, **options, and so on.

Code

def show_profile(name, **info):
    print("Name:", name)
    print("Extra info:", info)
    print("Type:", type(info))

show_profile("Ada", age=36, city="London", role="engineer")

Output

Name: Ada
Extra info: {'age': 36, 'city': 'London', 'role': 'engineer'}
Type: <class 'dict'>

name is a normal parameter. The keyword arguments age=36, city="London", and role="engineer" are gathered into the info dictionary automatically.

Keyword argument in the call Becomes in the dict
age=36 "age": 36
city="London" "city": "London"
role="engineer" "role": "engineer"

Looping Over the Dictionary

Because **info becomes a regular dict, you can loop over it with .items().

Code

def build_query(table, **filters):
    print("Table:", table)
    for key, value in filters.items():
        print(key, "=", value)

build_query("users", active=True, role="admin")

Output

Table: users
active = True
role = admin

No Extra Arguments

If the caller passes no extra keyword arguments, the ** parameter becomes an empty dictionary.

Code

def no_extra(**options):
    print(options)

no_extra()

Output

{}
Why use **? It lets a function accept a flexible set of named options without listing every possible parameter in the definition.
Placement rule A ** parameter must come after regular parameters. Example: def func(name, **info): — not def func(**info, name):.

Local vs Global Variables

Scope means where a variable exists and can be used. The two scopes beginners see most often are local and global.

Scope Created Visible
Local Inside a function Only inside that function
Global Outside all functions Anywhere in the file (unless shadowed)

Local Variables

A variable created inside a function is local. It exists only while that function runs.

Code

def show_local():
    message = "I am local"
    print("Inside:", message)

show_local()
print("Outside:", message)   # NameError

The last line raises NameError: name 'message' is not defined because message does not exist outside the function.

Global Variables

A variable created outside any function is global. You can read it inside a function, but assigning to the same name creates a new local variable unless you use the global keyword.

Code

message = "I am global"

def show_scope():
    message = "I am local"
    print("Inside:", message)

show_scope()
print("Outside:", message)

Output

Inside: I am local
Outside: I am global

Inside the function, message = "I am local" creates a local variable. It does not change the global message. This is an example of shadowing — covered in the next section.

Variable Shadowing

Shadowing happens when a inner name hides an outer name with the same spelling. Inside the function, Python uses the local version and the outer variable becomes temporarily invisible — like standing in front of a sign so someone behind you cannot see it.

Outer (global) Inner (local) What happens inside the function
message = "I am global" message = "I am local" Local message shadows the global one

Assignment Creates Shadowing

If you assign to a name inside a function, Python treats that name as local for the entire function, even on lines before the assignment.

Code

message = "I am global"

def show_scope():
    message = "I am local"   # shadows the global message
    print("Inside:", message)

show_scope()
print("Outside:", message)

Output

Inside: I am local
Outside: I am global

The global message is unchanged. Only the local copy was used inside the function.

Reading a Global (No Shadowing)

If you only read a global variable and never assign to that name inside the function, Python uses the global value. No shadowing occurs.

Code

count = 5

def read_global():
    print("Reading global count:", count)

read_global()
print("Global count still:", count)

Output

Reading global count: 5
Global count still: 5

Parameters Can Shadow Globals Too

A parameter is a local variable. If it has the same name as a global variable, the parameter shadows the global inside the function.

Code

name = "Global Name"

def greet(name):
    print("Parameter shadows global:", name)

greet("Ada")
print("Global unchanged:", name)

Output

Parameter shadows global: Ada
Global unchanged: Global Name
Shadowing trap: assignment makes the name local everywhere If you assign to a name anywhere in a function, Python treats it as local on every line in that function — even before the assignment.

Code

x = 10

def broken():
    print(x)   # UnboundLocalError
    x = 20

Calling broken() raises UnboundLocalError: cannot access local variable 'x' where it is not associated with a value. Python sees x = 20 and decides x is local, so print(x) runs before x has a value.

Avoid shadowing when you can Use different names inside functions (for example local_message instead of reusing message) to keep code easier to read and debug.

Modifying a Global Variable

If you truly need to change a global variable from inside a function, declare it with global. Use this sparingly — returning a value is usually cleaner.

Code

count = 0

def increment():
    global count
    count += 1

increment()
increment()
print("count:", count)

Output

count: 2
Prefer return over global For beginners, it is usually better to pass values in and return results out. Global variables make programs harder to follow and debug.

Summary

Functions let you package reusable logic. Define with def, call with parentheses, and use return to send values back.

Concept One-line meaning
Function Named block of reusable code
def Creates the function
Call Runs the function
return Sends a value back to the caller
Parameter Variable in the definition
Default value Fallback used when an argument is omitted
Argument Value passed in the call
**parameter Collects extra keyword arguments into a dict
Local variable Exists only inside the function
Global variable Exists at module level
Shadowing Inner name hides an outer name with the same spelling

Notable Observations

  • Always include parentheses when calling a function. greet() runs it; greet without parentheses refers to the function object itself.
  • Parameters and arguments are related but not the same word. Definition uses parameters; the call uses arguments.
  • Default values make parameters optional. Skip the argument and Python uses the default. Pass a value to override it. Required parameters (no default) must come first in the definition.
  • **parameter turns extra keyword arguments into a dict. Useful when a function needs to accept many optional named values without defining every one ahead of time.
  • Shadowing hides outer names, it does not delete them. A local variable or parameter with the same name as a global blocks access to the global inside that function. The global still exists when the function ends.
  • Assigning inside a function makes the name local for the whole function. That is why print(x) can fail before x = 20 if Python already treats x as local.
  • Start simple. Write small functions that do one thing, use clear names, and return values instead of relying on globals.
