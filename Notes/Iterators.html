What Iterators Are

An iterator is an object that lets you walk through a collection of values one at a time. Each time you ask for the next item, the iterator gives it to you until there is nothing left.

If you have ever used a for loop over a list or string, you have already used iterators — Python creates and uses them behind the scenes.

Iterator in plain terms An iterator is a “current position” marker moving through a sequence. It remembers where you are and hands you the next value when asked.

Iterable vs Iterator

These two words sound similar but mean different things:

Term What it is Example
Iterable Something you can loop over [10, 20, 30], "Python", {"a": 1}
Iterator The object that does the looping iter([10, 20, 30])

You start with an iterable (the data). Calling iter() on it gives you an iterator (the mechanism that produces values one by one).

Quick check Iterables have __iter__(). Iterators have both __iter__() and __next__().

iter() and next()

iter() creates an iterator from an iterable. next() asks the iterator for the next value.

Code

numbers = [10, 20, 30]
it = iter(numbers)

print(type(it))
print(next(it))
print(next(it))
print(next(it))
print(next(it))   # StopIteration

Output

<class 'list_iterator'>
10
20
30
StopIteration

The last line raises StopIteration because the iterator has no more values to give.

Strings Are Iterables Too

Code

for ch in "Py":
    print(ch)

it = iter("Py")
print(next(it), next(it))

Output

P
y
P y

Iterators and for Loops

A for loop is really shorthand for iterator work. Python roughly does this behind the scenes:

  1. Call iter() on the iterable
  2. Repeatedly call next() on the iterator
  3. Stop when StopIteration is raised

What you write

for n in [1, 2, 3]:
    print(n)

Output

1
2
3

Roughly equivalent manual version

numbers = [1, 2, 3]
it = iter(numbers)

while True:
    try:
        n = next(it)
        print(n)
    except StopIteration:
        break

Output

1
2
3
Prefer for loops They are shorter, clearer, and handle StopIteration automatically.

StopIteration

StopIteration is the signal that an iterator is finished. It is not usually an error you need to fix — it is how Python says “no more items.”

  • next() raises StopIteration when exhausted
  • A for loop catches it and ends quietly
  • Custom iterators raise it in __next__() when done

Common Iterables

Many built-in types are iterables:

Type What a loop gives you
list Each item
tuple Each item
str Each character
dict Each key (by default)
set Each item (unordered)
range Each integer in the range

Building a Custom Iterator

You can create your own iterator with a class. It needs two special methods:

  • __iter__() — returns the iterator object (often self)
  • __next__() — returns the next value, or raises StopIteration

Code

class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value

for n in CountDown(3):
    print(n)

Output

3
2
1

CountDown(3) is both iterable and its own iterator because __iter__ returns self.

Iterators and Generators

A generator is a convenient way to create an iterator. Instead of writing a class with __iter__ and __next__, you write a function that uses yield. Python turns that into an iterator automatically.

Every generator is an iterator, but not every iterator is a generator. For the full explanation of yield, pausing, and how generators compare to return, see Generators.html.

Approach How you build it Best for
Custom class __iter__ + __next__ Full control, complex state
Generator Function with yield Simple lazy sequences
Built-in iterable list, str, range, etc. Everyday collections
Related reference See Generators.html for how generator functions work, including yield vs return and generator expressions.

Summary

Iterators power looping in Python. An iterable holds data; an iterator walks through it one value at a time.

Concept One-line meaning
Iterable Object you can loop over
Iterator Object that produces values one at a time
iter() Gets an iterator from an iterable
next() Gets the next value from an iterator
StopIteration Signals that iteration is finished
for loop Uses an iterator automatically
Generator An easy way to create an iterator with yield

Notable Observations

  • Iterable ≠ iterator. A list is iterable. iter(my_list) gives you the iterator that walks through it.
  • Iterators are consumed. Once you have walked through an iterator, it is exhausted. To loop again, call iter() on the original iterable to get a fresh iterator.
  • for loops hide the iterator machinery. You rarely need to call next() yourself unless you are doing something manual or advanced.
  • Generators are iterators made easy. See Generators.html for the beginner-friendly guide to yield and lazy value production.
