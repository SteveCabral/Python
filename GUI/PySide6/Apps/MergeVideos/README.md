# Merge Videos

A PySide6 desktop application for merging split video files (`.MPEG`, `.FLV`,
`.AVI`, `.MP4`, and more) into a single file using FFmpeg.

See [docs/README.md](docs/README.md) for full documentation, requirements,
FFmpeg installation notes, and usage instructions.

## Quick Start

```bash
# Activate your virtual environment, then:
cd GUI/PySide6/Apps/MergeVideos
python main.py
```
