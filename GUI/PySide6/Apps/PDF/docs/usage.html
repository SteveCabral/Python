Prerequisites

  • Python 3.11 or later
  • Dependencies installed in your active virtual environment:
pip install -r requirements.txt

Starting the application

Run from the PDF directory:

cd GUI/PySide6/Apps/PDF
python main.py

The main window opens with empty file name/path fields and both grid rows showing —.

Rebuilding the EXE

To regenerate the packaged Windows app after a source change, run the project helper batch file from the PDF folder:

rebuild_pdf_app.bat

This script activates the project virtual environment and runs the PyInstaller build command:

python -m PyInstaller --noconfirm "PDF_Page_Size_Finder.spec"

The updated executable is written to dist\PDF_Page_Size_Finder.exe.

Step 1 — Select a PDF file

Click Open PDF and choose the file you want to inspect. Once selected:

  • The File Name field shows the PDF's file name.
  • The File Path field shows the full path on disk.
  • Every page in the document is read and classified as Letter (8.5 × 11 in), Legal (8.5 × 14 in), or another size.
Tip: Page size is compared using the page's long and short edges, so rotated (landscape) Letter or Legal pages are still recognised correctly.

Step 2 — Review the page ranges

The grid shows one row per size:

Row Page Range column
Letter Comma-separated ranges of every Letter-sized page, e.g. 1-2, 4
Legal Comma-separated ranges of every Legal-sized page, e.g. 3, 5-6
Other sizes One row per distinct page width and height, labeled in inches, e.g. 13 × 7

Consecutive page numbers are collapsed into a dash range (5-6); isolated pages are listed individually (4).

If a document has no pages of a given size, that row shows — and its Copy button is disabled.

Step 3 — Copy a page range

Click the Copy button next to any row to copy that row's page range to the clipboard. The status bar confirms what was copied.

Paste the copied text directly into the Pages field of the Windows Print dialog box to print only that size's pages, for example on the correct paper tray.

Notes

  • Page sizes are compared with a small tolerance (2 points) to absorb minor rounding differences between PDF producers.
  • Pages that are neither Letter nor Legal sized are grouped by width and height and shown in their own grid rows.
  • Selecting a new PDF file replaces the previous results.
  • The full path of the selected PDF is saved and used as the starting location the next time a PDF is opened.
